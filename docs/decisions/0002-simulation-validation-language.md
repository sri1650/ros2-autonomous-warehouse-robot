# ADR 0002: Make validation claims explicit

- Status: Accepted
- Date: 2026-10-23

## Decision

Repository documentation distinguishes implemented, configured, simulation-validated, and hardware-validated functionality. The initial release makes no physical-hardware claim and does not imply that application-layer interlocks are safety-rated.

## Consequences

This makes the portfolio more credible and gives future releases a clear evidence checklist.
